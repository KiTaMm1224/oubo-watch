# 応募ウォッチ（oubo-watch）

決まった募集サイトの一覧を毎日1回（17:23ごろ）見て、前回から増えた募集と、締切などの日付が変わった募集だけを `data/digest.md` にまとめます。
Claude の自動タスク「応募チャンス 4日ごと更新」は、このリストを読んで新しいものだけ詳しく確かめるので、サイトを毎回最後まで見て回るよりトークンが少なくて済みます。

- 見るサイト：`sources.json`（増やす・減らすときはここを直す）
- 結果：`data/digest.md`（Claude が読む短いリスト）、`data/state.json`（前回との比較用の記録）、`data/log.txt`（動いた記録）
- 取れなかったサイトは digest に「取得できなかった」と出て、そのサイトは Claude が今までどおり自分で見て回ります。
- 公開されている募集一覧だけを扱い、個人情報は入れません。robots.txt を守り、同じサイトには2秒以上あけて取りに行きます。
- 費用：GitHub の無料枠（非公開リポジトリは毎月約2,000分）の中で、1日数分しか使いません。

## tools/（Claude の自動タスクが使う道具）
Claude の自動タスクは、このリポジトリを clone して次の道具を使います。指示に長いスクリプトを書かずに済み、応募ナビを会話に読み込まずに扱えるので、トークンが減ります。
- `tools/navi.js`：応募ナビの HTML を扱う（`list` 一覧／`find` 重なりの確認／`has` digest の新着が応募ナビにあるか／`add` 項目を足して構文を確かめる）
- `tools/nc.js`：応募準備で、まだ考えていない新しい募集を探す（判定のプロフィールは、使うときに引数で渡す）
- `tools/ck.js`：応募物の文字数・決まり文句・【 】の残りを数える
